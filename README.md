# Devspace-mockups
html mockups for public demo
## Макеты DevSpace — PayG-биллинг

Интерактивные HTML-макеты экранов DevSpace с моделью оплаты по фактическому потреблению (PayG). Экраны связаны сквозной навигацией: список → создание / дашборд → управление, возврат через хлебные крошки.

| Экран | Описание | Ссылка |
|---|---|---|
| Список пространств | Списковая страница с колонкой «Потребление» (раскрываемые строки) | [devspace-payg-spaces-list.html](https://serjiott.github.io/devspace-mockups/devspace-payg-spaces-list.html) |
| Создание пространства | Форма без квот, цены за единицу ресурса, переключатель скидки и периода | [devspace-payg-create-space.html](https://serjiott.github.io/devspace-mockups/devspace-payg-create-space.html) |
| Дашборд пространства | Карточка k8s-campaign: текущее потребление и текущая стоимость | [devspace-payg-dashboard.html](https://serjiott.github.io/devspace-mockups/devspace-payg-dashboard.html) |
| Управление пространством | Лимиты ресурсов (слайдеры) и ограничение бюджета | [devspace-payg-manage-space.html](https://serjiott.github.io/devspace-mockups/devspace-payg-manage-space.html) |
| Управление пространством ADMIN| Лимиты ресурсов (слайдеры) и ограничение бюджета | [devspace-payg-manage-space-admin.html](https://serjiott.github.io/devspace-mockups/devspace-payg-manage-space-admin.html) |

> После обновления файлов страницы могут отдаваться из кэша — обновляйте жёстко (`Ctrl+Shift+R`).
